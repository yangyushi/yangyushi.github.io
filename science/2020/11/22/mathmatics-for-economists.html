Open Ball

The definition of an open ball in Rn is

Bε(x(0))={x∈Rn|‖x−x(0)‖<ε}.

It is open in a sense that we can always find open balls for every point inside one open ball.

Open Set

The set S is open if ∀x∈S there exist a open ball Bε(x)∈S

Example:

  1. The first quadrant R+2={x∈R2|x1,x2>0} is an open set.
  2. The open balls are open sets.
  3. The union set of all open sets is a open set. ( ∪α∈IAα is open set if Aα are open sets.)

Sequences in Rn

For x∈Rn to be one element of a sequence, we need to label x, we note the label as,

x(m)(m∈N)

and the sequance is therefore written as,

{x(m)}m=1∞.

Concretely, x(3) is the 3rd term of the sequence.

Convergence of the Sequence

Being convergent means there is a limiting value when m→∞. Suppose this value is x(0), we write

limm→∞x(m)=x(0).

We define convergence as the following,

∀ε>0, ∃ mε such that ∀ m≥mε, ∥x(m)−x(0)∥≤ε.

(The symbol mε means a typical value of m that depends on ε.)

Closed Set

Intuition: for a convergent sequence, whose term belongs to a set, we want to make sure its limit also belongs to the same set.

The set S∈Rn is closed, if any convergent sequence

{x(m)}m=1∞,x(m)∈S​

has the limit that belongs to S.

Example:

R+2 is not closed because we can find the following sequence that contradicts the definition.

x(m)=(11/m)→(10)∉R+2

The set

S={x∈R2|x1>0⏟not closed,x2≥0⏟not open}

is not open amd not closed at the same time.

Bounded and Compact

A set S∈Rn is called bounded if there exists a ball BR(0) such that S∈BR(0).

A set S∈Rn which is closed and bounded is called compact

Example:

A closed ball, expressed as the following function

cl Bε(x(0))={x∈Rn|‖x−x(0)‖≤ε}(cl means closure)

is a compact.

Functions in Rn

The normal functions is something like

y=f(x);x∈DD⊂R

The functions in Rn is something like,

y=f(x)=f(x1,…,xn);x∈DD⊂Rn

Example,

The function is y=1−x12−x22, and its natural domain is

D={x∈R2|x12+x22≤1}.

Domain of a function

D⊂Rn is the domain of a function, it consists of all permissable values of x, where the funciton looks like the following.

x∈Dy=f(x)∈R

we can give f(x) different values, forming the level sets

{x∈D|f(x)=y}

Continuity

For function f(x) where D is the domain; for x(0)∈D, the function is continous if the following expression is true.

limx→x(0)f(x)=f(x(0))

If a function is continues on any point in D we call the function continous on D

Th. Weierstrass

Let y=f(x) be continues on interval [a,b]. Then there exist m,M and x1,x2∈[a,b] such that m≤f(x)≤M and f(x1)=m;f(x2)=M

Composite Function

For function f(x),g(x) that are continous at x(0)∈D (D is called the common domain), the following composite functions are also continous at x(0).

f(x)±g(x)f(x)g(x)f(x)g(x)(g(x(0))≠0)
