简介

随机过程的概念

source

股票价格 ( S ) 是随机过程。想象一个 K 线图。对于任何时刻 ti，我们认为「这个时刻」的价格是一个随机变量。如果我们全知全能，我们可以写出这个随机变量 S(ti) 的 PDF。

因为一个 t 对应了一个随机变量 S(t)，那么「所有的时刻」对应了很多随机变量。我们把它们写成

{S(t),t∈[0,∞]}

总之，

A random process is a collection of random variables usually indexed by time.

实际上，时间是连续的。我们把这样的随机变量叫做 continuous-time random process。即使是一小段时间内，理论上也有无限多的随机变量被包含在随机过程中。

如果我们把时间看成由离散的时间点组成，那么我们就有 discrete-time random process，有时也被称为 random sequences。如果我们将时间视为一天一天的，那么我们就会得到离散的时间。

观察到一个具体的随机过程，例如，看到一个具体公司股票价格的涨跌，S(t)。这个行为可以看成是进行了一次实验，代表样本空间（所有平行世界）里的一次采样。这样得到的，具体的 S(t) 被称为 sample function 或者 sample path，它同样被称为（抽象的）S(t) 的一个实现。

CDF

从现在开始我们用 X(t) 来表示一个随机过程。在时刻 t0，X(t0) 是一个随机变量，其 CDF 为

FX(t0)(x)=P(X(t0)≤x)

对这个过程中，两个时刻 t1 和 t2 的联合 CDF 为

FX(t1)X(t2)(x1,x2)=P(X(t1)≤x1,X(t2)≤x2)

类似的我们也可以写出 PDF。

平均函数

对于随机过程 {X(t), t∈J}，其「平均函数」μX(t):J→R 为

μX(t)=E[X(t)]

（这个定义对连续和离散随机过程都成立）

关联函数

对于随机过程 {X(t), t∈J}，它的「自关联函数」RX 以及「自协方差函数」CX 分别为

RX(t1,t2)=E[ X(t1)X(t2) ]CX(t1,t2)=E[X(t1)X(t2)]−E[X(t1)]E[X(t2)]=RX(t1,t2)−μX(t1)μX(t2)=E[(X(t1)−E[X(t1)])(X(t2)−E[X(t2)])]

这个函数告诉我们 随机过程的 两个时刻 如何关联。

多个随机过程

我们有时候想要知道，多个随机过程 之间的关系。比如说，两家公司的 股票价格 是否相关。这个时候我们需要的，其实是多个随机过程的 cross-correlation 以及 cross-covariance。

对于两个随机变量 {X(t), t∈J} 和 {Y(t), t∈J}

RXY(t1,t2)=E[X(t1)Y(t2)]CXY(t1,t2)=Cov(X(t1),Y(t2))=RXY(t1,t2)−μX(t1)μY(t2)

两个「独立随机过程」的 cross-covariance 为零。

稳定过程

当一个随机过程的统计量不随着时间改变，我们说这个过程是一个「稳定过程」。

理想情况，strict-sense stationary

理想情况下，这个不变的统计量，是所有时间，对应的随机变量的 joint CDF。

当随机过程满足下面的等式，我们称之为稳定过程，

FX(t1)X(t2)⋯X(tr)(x1,x2,⋯,xr)=FX(t1+Δ)X(t2+Δ)⋯X(tr+Δ)(x1,x2,⋯,xr)

等式中，将时间增加 Δ 没有改变 joint CDF。

实际情况，weak-sense stationary WSS

上面的理想情况在现实中很难存在（例如，全球变暖影响了一切）。即使存在，也很难证明。有一个更弱的稳定条件。

这个条件是，对任意的 t1,t2,Δ∈R，下式成立。

E[X(t1)]=E[X(t2)]E[X(t1+Δ)]=E[X(t2+Δ)]

具体而言，对连续随机过程，有

μX(t)=μXfor all t∈RRX(t1,t2)=RX(t2−t1)for all t1,t2∈R

对离散随机过程，有

μX(n)=μXfor all n∈ZRX(n1,n2)=RX(n2−n1)for all n1,n2∈Z

例子：证明随机过程 WSS

定义连续随机过程 X(t), t∈R 为

X(t)=cos⁡(t+U)

并且 U 是 [0,2π] 上的均匀分布。证明 X(t) WSS。

WSS 过程的关联函数的性质

由于对 WSS 过程，RX(t1,t2)=RX(t1−t2) 所以重要的是时间差 τ=t1−t2，所以我们这样写此过程的 ACF

RX(τ)=E[X(t)X(t−τ)]=E[X(t+τ)X(t)]

考虑 X(t), t∈R，它的关联函数是 RX(τ) 是

RX(0)=E[X(t)2]

我们将 E[X(t)2] 称为 X(t) 在时刻 t 的 expected (average) power。

RX(0)=E[X(t)2]≥0RX(τ)=RX(−τ)|RX(τ)|≤RX(0)

联合 WSS 过程

对于两个随机过程 {X(t),t∈R} 和 {Y(t),t∈R}，如果它们满足下面连个条件，则称这两个过程是联合 WSS 过程，

  1. X(t) 和 Y(t) 分别是 WSS 过程。
  2. RXY(t1,t2)=RXY(t1−t2)

循环稳定过程

严格 cyclostationary

有一些随机过程具有周期性，被称为 cyclostationary processes。更正规的描述是，随机变量

X(t1),X(t2),⋯,X(tr)

和下面的随机变量具有相同的 joint CDF。

X(t1+T),X(t2+T),⋯,X(tr+T)

一个严格的 cyclostationary 过程的例子是：对于随机过程 X(t),t∈R，并且

X(t)=Acos⁡(ωt)

其中 A 是一个随机变量。很容易证明

X(t+2πω)=Acos⁡(ωt+2π)=Acos⁡(ωt)=X(t)

Weak-sense Cyclostationary, WSC

对于连续随机过程 X(t),t∈R，如果存在正实数 T 满足

μX(t+T)=μX(t)for all t∈RRX(t1+T,t2+T)=RX(t1,t2)for all t1,t2∈R

随机变量的微积分

很多现实中的动力学是通过微分方程描述的。如果「随机性」混在了里面，我们需要对系统里的随机性来进行微积分。

均方连续

假设 X(t) 是连续时间随机过程，我们说 X(t) 在时间 t 满足 mean-square continuous，如果满足下面的关系

limδ→0E[|X(t+δ)−X(t)|2]=0

这个关系的特点是，它不要求 X(t) 的每一个实现都是连续函数。只要平均而言 X(t+δ)−X(t) 很小就可以了。

微积分

定义了 mean-square continuous 之后，我们可以将「可微」和「可积」的概念延伸到「均方可微」以及「均方可积」。假设 X(t) 是一个随机过程，那么它的微分

Y(t)=ddtX(t)

也是一个随机过程。

例子

假设我们有下面的随机过程

X(t)=A+Bt+Ct2t∈[0,∞)

其中 A,B,C 均为随机变量，那么 X(t) 的微分是

X′(t)=B+2Ctt∈[0,∞)

处理微积分

忽略掉具体的数学细节，处理随机过程的微积分的关键点是

differentiation and integration are linear operations

这代表着，微积分操作 和 求期望操作 的「顺序」是可以替换的（如果 X(t) 的微分 well defined）。

E[∫0tX(u)du]=∫0tE[X(u)]duE[ddtX(t)]=ddtE[X(t)]

另一个例子

对于随机过程 X(t) 和它的微分 X′(t)=ddtX(t)，证明

RXX′(t1,t2)=∂∂t2RX(t1,t2)

证明过程

由 cross-correlation 的定义

RXY(t1,t2)=E[X(t1)Y(t2)]

有

RXX′(t1,t2)=E[X(t1)X′(t2)]=E[X(t1)ddt2X(t2)]=E[∂∂t2X(t2)X(t1)]=∂∂t2E[X(t1)X(t2)]exchangable=∂∂t2RX(t1,t2)

正态随机过程

Jointly normal

如果对于很多随机变量 X1,X2,…Xn，对任意 ai∈R

a1X1+a2X2+⋯+anXn

都是一个正态随机变量，则说明 X1,X2,…Xn 是 jointly normal

正态随机矢量

对于随机变量构成的矢量

X=[X1X2⋮Xn]

其中 X1,X2,…Xn jointly normal，则这个矢量是正态随机变量，normal random vector。如果正态随机变量 X 的均值是 m，协方差矩阵是 C，则 X 的 joint PDF 是

fX(x)=1(2π)n2detCexp⁡{−12(x−m)TC−1(x−m)}

正态随机过程

对于随机过程 X(t),t∈J，如果对于所有

t1,t2,…,tn∈J

随机变量 X(t1),X(t2),…,X(tn) jointly normal，那么这个随机过程就是「正态随机过程」(Gaussian (normal) random process)。

正态随机过程的一个特点是，如果 X(t) 满足 WSS，那么 X(t) 是严格的稳定过程。

联合正态过程

对于两个随机过程 X(t),t∈J 和 Y(t),t∈J，如果对于任何的 t1,t2,…,tm 和 t1′,t2′,…,tm′，下面的随机变量们

X(t1),X(t2),⋯,X(tm), Y(t1),Y(t2),⋯,Y(tm)

jointly normal，则 X(t) 与 Y(t) 是联合正态过程。

如果两个联合正态过程 X(t) 与 Y(t) 不相关，

CXY(t1,t2)=0for all t1,t2

则 X(t) 和 Y(t) 是两个独立的随机变量。

记数过程

对随机过程 N(t),t∈[0,∞)，如果 N(t) 是从时刻 0 到时刻 t 的「事件发生次数」，则此过程被称为「记数过程」(Counting Process)。

对于记数过程，我们假设

  1. N(0)=0
  2. 对于所有 t∈[0,∞) 有，N(t)∈0,1,2,⋯
  3. 对于时刻 s， 0≤s<t，则 N(t)−N(s) 表示时间间隔 (s,t] 内，事件发生的次数。

由于记数过程最常见的例子是「顾客到达商场」，所以我们把记数过程中发生的事件叫做「到达」。

独立增量

（简而言之就是，随机过程每个时刻的「增量」都是独立的。）

对于连续时间过程 X(t),t∈[0,∞)，如果对于所有的 0≤t1<t2<⋯<tn，下面的随机变量们

X(t2)−X(t1), X(t3)−X(t2)，⋯,X(tn)−X(tn−1)

都是独立的，那么 X(t) 拥有 独立增量。

静态增量

对于 连续时间 随机变量 X(t),t∈[0,∞)。如果对于所有的 t2>t1≥0 以及所有的 r>0，随机变量

X(t2)−X(t1)

和

X(t2+r)−X(t1+r)

具有相同的 概率分布。那么，我们说 X(t) 具有「独立增量」。

换言之，如果 随机变量的增量 只依赖于 时间差，不依赖于 时间点，那么随机变量就拥有 静态增量。

泊松过程

「泊松过程」是最常见的一种 计数过程。这个过程的情形是，某种事件会随机发生，但是 仿佛 有一个内在的固定速率。

一个例子是，我们知道「地震」的发生是随机的。但是从历史上来看，地震发生的「速率」是 2 次 / 月。不过除了 「速率」这个信息，地震的发生是彻底随机的。

泊松随机变量

令 X 为一个泊松随机变量。它的参数为 μ，写作 X∼Possion(μ)。如果 X 的取值范围是 RX=0,1,2,…，那么，X 的概率质量函数 (PMF) 是

PX(k)={e−μμkk! for k∈RX0 otherwise 

泊松过程具有三个值得注意的性质

  1. E[X]=μ; Var[X]=μ
  2. 如果一组随机变量 Xi∼Possion(μi)，且这些随机变量都相互独立。那么 ∑iXi∼Possion(∑iμi)
  3. 泊松分布是二项分布的极限情况。（取样间隔无限短）

泊松过程的描述

假设某件事的发生是彻底随机的，不过发生的「速率」是 λ。

我们通过将「时间」分割成小段区间，来研究事件的「到达」。下面是时间分割的一个图示。

我们将第 k 个间隔写作 ((k−1)δ,kδ]。在每一个「间隔」中，我们获得一个「到达」的概率为

P(H)=p(binomial distribution)=λδ(arrival chancetime×time)

只要我们的时间间隔 δ 无限小，那么我们总可以保证每个间隔「最多只有一个 到达」。一个具体的图像是

如果我们定义 N(t) 为从事件 t=0 到 t=t 的「到达次数」，那么 N(t)∼Binomial(n,p),p=λδ。在 δ→0 的情况下，N(t)∼Possion(λt)。

更进一步，我们可以发现在 任意时间间隔 τ 内，到达次数服从 Possion(λτ)。（与初始时间无关）。

泊松过程的定义 1

在任意时间段 λ>0 内，计数过程 {N(t),t∈[0,∞)} 如果满足下面的条件，则被定义为 泊松过程

  1. N(0)=0
  2. 随机过程 N(t) 拥有「独立增量」。
  3. 任意时间段 τ 内的 到达次数 服从泊松分布 Possion(λτ)

泊松过程的定义 2

我们可以根据「增量」来给出泊松过程的 另一个定义。让我们考察 连续时间里 的一个小时间段 Δ。如果我们研究的过程是 泊松过程，那么

P(N(Δ)=0)=e−λΔ=1−λΔ+λ22Δ2−⋯ (Taylor Series) =1−λΔ+o(Δ)P(N(Δ)=1)=λΔ+o(Δ)P(N(Δ)≥2)=o(Δ)

这个推导得到了 泊松过程 的第二种定义

  1. N(0)=0
  2. 随机过程 N(t) 拥有「独立、静态的增量」。
  3. 下面的等式成立
P(N(Δ)=0)=1−λΔ+o(Δ)P(N(Δ)=1)=λΔ+o(Δ)P(N(Δ)≥2)=o(Δ)

到达时间

假设 N(t) 是速率为 λ 的泊松过程。令 X1 为第一次「到达」事件发生的 时间。那么 X1 是一个随机变量。我们可以根据 泊松分布写出

P(X1>t)=P( no arrival in (0,t] )=exp⁡(−λt)

据此我们可以写出 X1 的 PDF

FX1(t)={1−e−λtt>00 otherwise 

且我们发现 泊松过程的 到达时间 服从 指数分布

间隔时间

假设 N(t) 是速率为 λ 的泊松过程。令 X2 为 第一次到达事件 和 第二次到达事件 之间的「间隔」。那么 X2 也是一个随机变量。我们可以根据 泊松分布写出

P(X2>t∣X1=s)=P( no arrival in (s,s+t]∣X1=s)=P( no arrivals in (s,s+t]) (independent increments) =e−λt

我们发现 泊松过程的 间隔时间 也服从 指数分布。

推广到任意的第 i 个间隔时间，对于泊松过程，它们服从指数分布。

此外，服从指数分布的 随机变量 没有记忆。即，

P(X>x+a∣X>a)=P(X>x), for a,x≥0

这个和泊松过程中，每个间隔相互独立是一致的。

Gamma 分布

现在让我们考虑「到达时间的分布」，它们可以写成

T1=X1T2=X1+X2T3=X1+X2+X3…

对于第 n 次到达事件，到达时间 Tn 这个随机变量是 n 个独立的、服从泊松分布的 随机变量的和。我们把 Tn 服从的分布称为 Gamma 分布，也叫 Erlang 分布。

Tn=∑inXi∼Gamma(n,λ)for n=1,2,3,…

我们可以写出 Gamma 分布的 PDF：

fTn(t)=λntn−1exp⁡(−λt)(n−1)!(t>0)

此外，由于我们知道 X 的期望和方差，

E[X]=λ−1Var[X]=λ−2

则 Gamma 分布的期望和方差是

E[Tn]=nE[X]=nλ−1Var[Tn]=nVar[X]=λ−2

模拟泊松过程

一个实际模拟泊松过程的方法如下。假设速率为 λ。

  1. 生成 n 个 i.i.d. 的随机变量 X1,X2,X3,…，其中 Xi∼Exponential(λ)
  2. 通过对 Xi 求和得到 每个事件 的 到达时间
T1=X1T2=X1+X2T3=X1+X2+X3…
