# Build my Blog


## Installation

1. install ruby
2. install bundler: `gem install bundler`
3. install dependencies: `bundle install`


## Commands

On Linux / macOS:

```sh
make publish   # build and push to GitHub Pages
make serve     # local dev server
```

On Windows (Python 3 + Git required):

```sh
python publish.py publish   # build and push to GitHub Pages
python publish.py build     # build only
```
